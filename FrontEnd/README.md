# Frontend React

Este proyecto utiliza Vite y React para la interfaz de usuario.

## Ejecutar el frontend

1. Abrir una terminal en `FrontEnd`.
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Iniciar la aplicación:
   ```bash
   npm run dev
   ```
4. Abrir la URL que muestra Vite (normalmente `http://127.0.0.1:5173`).

## Requisitos

- El backend debe estar ejecutándose en `http://127.0.0.1:8000` antes de usar el frontend.
- El frontend hace peticiones al backend en la ruta `/api/agent/query`.

## Notas

- `Doc/` es solo para los documentos de conocimiento del modelo.
- `Docs/` y `QA/` contienen la guía de ejecución y las pruebas, respectivamente.
